# Need of Containers
#--------------------
When we creates our app like well-structured like Controller, Service
Repository, Routes then we have to pass each Class into another.

   After creating Containers we have to still write too many codes for
Binding the classes.
    Here Reflections comes in picture: These allow PHP to inspect classes
at runtime.

What is Reflection?
---------------------
Reflection allows PHP to inspect its own code while the application is running.

"What is a Service Container?"
------------------------------
A Service Container is responsible for creating, resolving, and 
managing application dependencies.

"What is Reflection used for in a DI container?"
-------------------------------------------------
PHP Reflection allows the container to inspect a class's constructor 
and determine its required dependencies at runtime, allowing the 
container to resolve and instantiate objects automatically.

What is a Singleton?
---------------------
Create the object once and return the same object every time it is requested.

What is the HTTP Kernel?
--------------------------
Think of the Kernel as the manager of an HTTP request.
    The Kernel coordinates the HTTP lifecycle.
